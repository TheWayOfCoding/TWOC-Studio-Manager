Key rules

  • id stable key on every entity — presets, modes, default sets, modalities, and shows all reference devices by id.
  • name / label display-only — renaming equipment never breaks a link.
  • hard links (device→zone/profile, preset/default devices, studio defaults) refuse to boot or save when broken.
  • soft links (power groups, plugs, OBS scenes/targets, IR colors) degrade honestly at apply time.
  • Value spans come from profile specs via GET /api/studios/{studio}/ranges — one resolver for the Control sliders, the Default-sets builder, and this page.
